# Kiertly

Kiertly is an Expo + React Native + TypeScript mobile app starter.

This repository currently contains only the technical app base, not the old Cloyva product idea or fashion marketplace content.

## Tech stack

- Expo
- React Native
- TypeScript
- expo-router
- Supabase client dependency ready for later use

## Start buttons / scripts

The same app-start scripts from the Cloyva base are included in `package.json`:

```bash
npm run start
npm run start:clear
npm run android
npm run ios
npm run web
npm run typecheck
```

## Local setup

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npm run start
```

Start web preview:

```bash
npm run web
```
